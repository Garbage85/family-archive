# Family Archive 0.2

Self-hosted семейное древо на PocketBase и Family Chart.

В версии 0.2 встроенный редактор Family Chart отключён. Нажатие на человека открывает собственную боковую карточку с русскими полями и понятными кнопками добавления родственников.

## Обновление уже установленного сайта

```bash
cd ~/family-archive-0.2
sudo ./scripts/deploy-update.sh
```

После обновления откройте сайт с `?v=020`, чтобы обойти кэш браузера.

## Возможности

- собственная карточка человека;
- имя, фамилия, отчество, пол, даты, место рождения, профессия и заметки;
- фотография;
- добавление родителя, супруга, ребёнка, брата или сестры;
- удаление человека;
- поиск, масштабирование и смена ориентации;
- роли, предложения изменений и модерация;
- экспорт JSON;
- дата рождения начального профиля Алексея: 08.12.1985.

## Установка с нуля

```bash
sudo ./scripts/install.sh
```
